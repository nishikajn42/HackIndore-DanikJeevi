DanikJeevi (दैनिकजीवी)

Restoring dignity to the hands that build Bharat.

A voice-first, AI-driven work exchange bridging the information gap in India’s daily-wage informal economy.

💡 The Problem

    Over 2 billion people worldwide (more than 60% of the global workforce) operate in the informal economy. In developing nations like India, daily-wage laborers—painters, masons, domestic helpers, and construction workers—lose 30% to 40% of their monthly earning potential simply waiting at physical Labour Chowks hoping for work.

    Information Gap: Workers and local employers exist in close physical proximity but have no real-time discovery channel.

    Middlemen Exploitation: Middlemen take 10%–20% cut from daily earnings with zero contractual transparency.

    Zero Financial Identity: Without recorded work history or pay stubs, informal workers remain cut off from institutional credit and loans.

    Safety Vulnerabilities: Women in informal labor lack safety mechanisms, standard pricing, and legal protection.

🎯 Our Solution

    DanikJeevi replaces the uncertain, street-corner Labour Chowk with an accessible, real-time matching ecosystem. By offering voice-first channels alongside digital interfaces, DanikJeevi ensures that technology empowers workers regardless of their digital literacy levels or smartphone ownership.

✨ Key Features

    🗣️ Dual-Path Voice & App Accessibility
    Smartphone Users: Clean, lightweight mobile app interface with voice-command support in regional languages (Hindi, Marathi, English).

    Keypad Phone Users: Full access via Toll-Free IVR, automated voice calls, and WhatsApp/SMS bots for workers without smartphones.

    🆔 Government e-Shram UAN Integration
    Seamless onboarding using the worker's government-issued e-Shram Universal Account Number.

    Automatic mapping of workers to government welfare, pension, and accident insurance schemes (e.g., PMSBY) based on their profile.

    ⭐ Portable Trust Score
    Ratings and completion history belong directly to the worker and carry over across all jobs and employers.

    Higher trust scores increase priority matching for local job requests.

    📸 Verified Payment Engine
    A job cannot be marked closed until the worker confirms payment receipt.

    Supports proof uploads via cash photos or UPI screenshots to prevent wage delays and default.

    🚨 Women's Safety & Active SOS
    Integrated one-tap SOS button active throughout any ongoing job.

    Triggering an SOS instantly alerts emergency contacts, flags the support team, and temporarily freezes the employer's account pending investigation.

    📊 Digital Proof of Income
    Every completed job automatically generates a downloadable invoice and work ledger.

    Serves as verifiable proof of income for micro-loans, bank accounts, and social security applications.


🛠️ Tech Stack
    Frontend: React.js, Tailwind CSS, Framer Motion, Lucide Icons

    Backend: Node.js, Express.js

    Database: MongoDB / PostgreSQL

    Voice & Telecom Services: Web Speech API, Twilio / Exotel IVR Integration, 

    WhatsApp Business API

    Authentication: OTP Service & e-Shram UAN Mapping API


🚀 Getting Started

    Prerequisites

    Ensure you have the following installed on your machine:

        Node.js (v18.0.0 or higher)

        npm or yarn

        Git

    Installation & Setup
        1. Clone the Repository

            git clone https://github.com/your-username/danikjeevi.git

            cd danikjeevi

        2. Install Dependencies

            npm install

        3. Configure Environment Variables

        Create a .env file in the root directory and add your API credentials:

            PORT=5000

            MONGODB_URI=your_mongodb_connection_string

            JWT_SECRET=your_jwt_secret_key

            TWILIO_ACCOUNT_SID=your_twilio_sid

            TWILIO_AUTH_TOKEN=your_twilio_auth_token

        4. Run the Development Server

            npm run dev

    Open http://localhost:5173 (or http://localhost:3000) in your browser to view the application.
